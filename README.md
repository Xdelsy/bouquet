# Bouquet

Небольшая анимация на Python (tkinter + numpy): открывается конверт, из него появляется букет цветов, а затем из частиц складывается надпись. Всё рисуется символами в окне tkinter.

## Готовая сборка (без установки Python)

### Из Releases

Откройте страницу репозитория → **Releases** → последний релиз и скачайте:

- **Windows:** `Bouquet.exe`
- **macOS:** `Bouquet-mac.zip` (распакуйте, внутри будет `Bouquet.app`)

### Из Actions

Если релиза нет, откройте вкладку **Actions** → workflow **Build** → последний успешный запуск. Внизу страницы, в разделе **Artifacts**, лежат архивы:

- `Bouquet-windows` — внутри `Bouquet.exe`
- `Bouquet-mac` — внутри `Bouquet-mac.zip`

Скачивать артефакты из Actions могут только пользователи, вошедшие в GitHub.

### Предупреждение Windows SmartScreen

Программа не подписана, поэтому Windows может показать окно «Windows защитила ваш компьютер». Нажмите **«Подробнее»** → **«Выполнить в любом случае»**.

Первый запуск `Bouquet.exe` может занять несколько секунд: файл распаковывается во временную папку.

### Предупреждение macOS

macOS может сообщить, что приложение от неустановленного разработчика. Сделайте **правый клик** (или Ctrl+клик) по `Bouquet.app` → **«Открыть»** → **«Открыть»** в появившемся окне. Дальше приложение будет запускаться обычным двойным кликом.

Если macOS пишет, что приложение «повреждено», выполните в Терминале:

```bash
xattr -cr /путь/к/Bouquet.app
```

## Запуск из исходников

Нужен Python 3 с tkinter (в установщике с python.org он есть).

```bash
pip install numpy
```

```bash
python bouquet.py
```

## Управление

| Клавиша | Действие |
|---|---|
| **R** | начать заново |
| **Пробел** | пауза / продолжить |
| **← / →** | поворот камеры |
| **Esc** | выход |

Клавиша R срабатывает при английской раскладке и выключенном Caps Lock.

## Сборка вручную

```bash
pip install pyinstaller numpy
```

```bash
pyinstaller --onefile --windowed --name Bouquet bouquet.py
```

Готовый файл появится в папке `dist/`.
